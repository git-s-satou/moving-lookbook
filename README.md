# IN MOTION / EDITION 01

女性モデルが動きながら2種類のニットベストを着替える、固定カメラのWebデモです。アイボリーのセーラーカラーベストと紺のクルーネックベストを選べます。映像はローカルのMiniMax H3で生成し、商品欄は映像と同じ着用ディテール画像を使用しています。映像・画像ともAI生成による着用イメージです。

## 起動

このフォルダで `python -m http.server 8000 --bind 127.0.0.1` を実行し、http://127.0.0.1:8000/ を開いてください。`file://`表示では動画の読み込みやブラウザ検証が異なるため、ローカルHTTPを使います。

商品を選ぶと、現在の待機動画の終端で着替えを開始します。動画の下で再生を停止・再開できます。読み込みに失敗した場合は再試行を表示します。

## 素材

`assets/` に、A待機・A→B・B待機・B→AのMP4と、A/Bの着用ディテールJPGを収録しています。動画は同じ画角のH.264、480×640、24fps、音声なしです。商品画像は単品の商品写真ではありません。

検証結果と制約は [verification.md](verification.md) を参照してください。
